# Diagnóstico y Requerimiento: Error en Recaudos - Pagos de Arrendatarios

## Diagnóstico

### Error en UI
```
Error al cargar recaudos: column "fecha_inicio" does not exist LINE 12: ORDER BY FECHA_INICIO DESC
```

### Causa Raíz
El archivo `src/infraestructura/persistencia/repositorio_recaudo.py` contiene dos consultas SQL que referencian la columna `FECHA_INICIO` en la tabla `CONTRATOS_MANDATOS`, pero **el nombre real de la columna es `FECHA_INICIO_CONTRATO_M`**.

### Ubicaciones del Error

| Ubicación | Línea | Método |
|-----------|-------|--------|
| `repositorio_recaudo.py` | 405 | `contar_con_filtros()` |
| `repositorio_recaudo.py` | 615 | `listar_paginado()` |

Ambas ocurren en subqueries LATERAL que obtienen el `GRUPO_OPERATIVO` del contrato de mandato activo más reciente:

```sql
LEFT JOIN LATERAL (
    SELECT GRUPO_OPERATIVO
    FROM CONTRATOS_MANDATOS
    WHERE ID_PROPIEDAD = ca.ID_PROPIEDAD
      AND ESTADO_CONTRATO_M = 'ACTIVO'
    ORDER BY FECHA_INICIO DESC  -- ← ERROR: columna inexistente
    LIMIT 1
) cm ON true
```

### Evidencia de la Columna Correcta

1. **Entidad `ContratoMandato`** (`src/dominio/entidades/contrato_mandato.py:31`):
   ```python
   fecha_inicio_contrato_m: str = ""
   ```

2. **INSERT en repositorio** (`repositorio_contrato_mandato_postgres.py:23`):
   ```sql
   INSERT INTO CONTRATOS_MANDATOS (..., FECHA_INICIO_CONTRATO_M, ...)
   ```

3. **Uso correcto en reportes** (`repositorio_reportes.py:275`):
   ```sql
   ORDER BY FECHA_INICIO_CONTRATO_M DESC  -- ← Correcto
   ```
