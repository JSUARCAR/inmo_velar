### Especificaciones Técnicas

- **Formato**: PNG
- **Resolución**: 1920x1080 (Full HD) o superior
- **Calidad**: Alta (sin compresión excesiva)
- **Nomenclatura**: Usar los nombres exactos indicados en la tabla

### Notas Importantes

1. **Capture pantallas completas** (no solo partes del Dashboard)
2. **Asegúrese de que los datos sean visibles** y legibles
3. **Incluya la barra de navegación** del navegador para contexto
4. **Evite información sensible** en las capturas (nombres completos, documentos, etc.)
5. **Use datos de ejemplo** si es necesario para privacidad

### Después de Capturar

1. Guarde los archivos en esta carpeta: `docs/assets/screenshots/Dashboard/`
2. Verifique que los nombres de archivo coincidan con los indicados
3. Las imágenes ya están referenciadas en el archivo `dashboard.md`

### Referencia en el Manual

Las imágenes se incluyen en el manual usando la sintaxis MkDocs:

```markdown
![Descripción de la imagen](../../assets/screenshots/Dashboard/nombre-archivo.png)
```
