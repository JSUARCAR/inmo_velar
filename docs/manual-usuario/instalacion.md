# Instalación y Acceso al Sistema
## Requisitos previos
- Navegador actualizado (Chrome, Firefox, Edge)
- Conexión a internet estable
- Usuario y contraseña provistos por el administrador
## Acceso
1. Abrir la URL del sistema provista por el administrador
2. Ingresar usuario y contraseña
3. Presionar **Ingresar**
## Recuperación de credenciales
| Situación | Acción |
|-----------|--------|
| Olvidé mi contraseña | Contactar al administrador del sistema |
| Usuario bloqueado | Solicitar desbloqueo por soporte |
| Primer acceso | Usar credenciales temporales enviadas por email |
> [!WARNING]
> Nunca comparta sus credenciales con terceros. El sistema registra toda la actividad por usuario.
